# UP-EYE-DAWN agent context pack

Read this first. Do not move or rewrite original evidence. The demo is isolated in `up-eye-dawn-demo`; INSECE remains a separate external source.

UP-EYE-DAWN is framed as autonomous field intelligence: fixed Sentinel, mobile rover, drone, soil probe and cloud/data layer. Current evidence supports a documented architecture and a deterministic demo, not a fully validated deployed system.

- `SENTINEL_003`: primary dossier describes a fixed ~4 m V1 with 12.8 V/50 Ah LiFePO4, 150–200 Wp recommendation, 4G/Wi‑Fi and optional LoRa. CAD, wind calculations, electrical drawings, fabrication and tests are missing. 5 m/telescopic/24 V/400 Wp/Starlink/Matrice claims conflict or belong to later/demo concepts.
- `ROVER_001`: concept images, a project PDF and a test video exist. Identity/name is conflicting; “Wall‑E Sentinel” is a configurable working name requiring legal review. No verified local production CAD or ROS model was found.
- Drone/dock/probe: plausible concepts only until exact models, datasheets, compatibility, calibration and tests are supplied.
- NDVI/AI: demo data is synthetic and labelled. No operational INSECE NDVI algorithm, model, dataset or metrics were found in the audited workspace.
- Demo: React/Vite web, Fastify/WebSocket API and deterministic TypeScript simulation. PostGIS/Redis launch in Compose, but the API currently uses an in-memory adapter. Procedural product models are placeholders.
