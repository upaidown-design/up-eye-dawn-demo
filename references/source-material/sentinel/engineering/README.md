# Dosier Tecnico - SENTINEL V3

Este dosier convierte el concepto visual de `SENTINEL V3` en una base tecnica para desarrollo, validacion y presentacion.

## Archivos

- `00_resumen_ejecutivo.md`: vision del producto, alcance y propuesta de valor.
- `01_especificaciones_tecnicas.md`: especificaciones funcionales, mecanicas, electricas y de comunicaciones.
- `02_arquitectura_sistema.md`: modulos, interfaces y flujo operativo.
- `03_energia_autonomia.md`: dimensionamiento inicial de energia solar, bateria y consumos.
- `04_bom_costes.csv`: lista preliminar de componentes y rangos de coste.
- `05_plan_mvp_fases.md`: ruta de desarrollo por fases.
- `06_riesgos_normativa.md`: riesgos tecnicos, legales y de seguridad.
- `07_requisitos_pendientes.md`: datos que hay que confirmar antes de fabricar.
- `assets/`: imagen y video conceptual originales copiados como referencia.

## Estado del Proyecto

Estado actual: concepto visual avanzado, pendiente de ingenieria de detalle.

Madurez estimada: TRL 2-3. Existe una idea de sistema y una maqueta visual, pero faltan prototipo funcional, ensayos, planos, calculos estructurales, seleccion final de componentes y validacion normativa.

## Nota Importante

Las especificaciones marcadas como "estimadas" son valores de diseno inicial. No deben usarse para compra, fabricacion o certificacion sin validacion de proveedor, calculo electrico y prueba de campo.
